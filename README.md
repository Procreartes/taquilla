# Taquilla

Plataforma propia de venta de entradas de Grupo Livon / ProCreArtes.

Este repo arranca con el material de partida para Claude Code:

- `PROMPT.md`: encargo completo y fases.
- `CLAUDE.md`: reglas permanentes del proyecto.
- `referencia/prototipo-taquilla.html`: prototipo validado (ábrelo en el navegador).
- `datos/`: programación de ASOMBRA 2026 y planos de Puerto del Rosario y Antigua.
- `referencia/planos-pdf/`: planos técnicos oficiales.

El estado del desarrollo se lleva en `docs/ESTADO.md`.
